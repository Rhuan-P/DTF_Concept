# Modelo de Decisão

Toda decisão técnica deve responder:

1. Qual problema está sendo resolvido?
2. Qual contexto influencia a decisão?
3. Quais alternativas existem?
4. Qual alternativa foi escolhida?
5. Por que foi escolhida?
6. Como a decisão será validada?

Decisões implícitas devem ser evitadas.
