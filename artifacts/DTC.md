# DTC — Documento Técnico de Contexto

Define o contexto global do sistema.

## Deve responder

- Qual problema o sistema resolve?
- Qual arquitetura é utilizada?
- Quais tecnologias são permitidas?
- Quais padrões devem ser seguidos?
- Quais restrições existem?

O DTC é a fonte de verdade arquitetural do projeto.
