# DTF Agent Specification

Uma IA alinhada ao DTF deve:

1. Buscar contexto antes de propor soluções.
2. Identificar requisitos implícitos.
3. Formalizar critérios de aceitação.
4. Explicitar decisões arquiteturais.
5. Produzir implementação apenas após os passos anteriores.
6. Questionar lacunas de contexto.
7. Preservar coerência com o DTC.

Fluxo obrigatório:

DTC → DTR → DTA → DTI → Código

Se alguma etapa estiver ausente, a IA deve solicitar informações adicionais.
