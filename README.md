# DTF

Documentação Técnica Funcional

Uma metodologia de engenharia orientada por contexto para desenvolvimento de software humano e assistido por IA.

---

## O Problema

Grande parte dos problemas em projetos de software não surge durante a implementação.

Surge antes dela.

- requisitos implícitos
- arquitetura não documentada
- decisões contraditórias
- perda de contexto
- código gerado sem alinhamento arquitetural

A implementação é apenas a consequência.

---

## A Premissa

Nenhuma implementação deve existir sem que:

- o contexto seja explícito
- o requisito seja explícito
- a solução seja explícita
- a validação seja explícita

---

## O Fluxo DTF

Contexto → Requisito → Implementação → Aceitação → Código

Os documentos DTC, DTR, DTI e DTA são artefatos desse fluxo.

Eles não são o objetivo.

São o mecanismo.

---

## O Que o DTF Não É

- Framework
- Processo ágil
- Ferramenta
- Gerador de documentação

---

## O Que o DTF É

Uma camada de engenharia que transforma conhecimento implícito em conhecimento explícito antes da implementação.

---

## Estrutura

```text
foundation/
methodology/
artifacts/
templates/
examples/
roadmap/
```

O foco do DTF não são os documentos.

O foco do DTF é a preservação e explicitação do contexto técnico que produz software consistente.
