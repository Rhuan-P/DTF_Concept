# DTF para IA

## Princípio

A IA não deve receber apenas prompts.

A IA deve receber contexto estruturado.

## Hierarquia de Consumo

DTC → DTR → DTA → DTI → Implementação

## Comportamento Esperado

Uma IA alinhada ao DTF deve:

1. Identificar contexto ausente.
2. Identificar requisitos implícitos.
3. Formalizar critérios de aceitação.
4. Propor implementação.
5. Produzir código somente após os passos anteriores.

## Regra

Código sem contexto é uma hipótese.

Código com contexto é engenharia.
