# Filosofia DTF

O DTF parte da premissa de que software é consequência de decisões.

Problemas de software raramente são problemas de implementação.

Normalmente são problemas de contexto, entendimento, alinhamento ou arquitetura.

O objetivo do DTF é transformar conhecimento implícito em conhecimento explícito antes da implementação.

O código não é a fonte da verdade.

A fonte da verdade é o contexto técnico formalizado.
